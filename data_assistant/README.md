# Data Assistant

React + Vite + Tailwind CSS + TypeScript scaffold for the Data Assistant prototype described in `docs/data-assistant-development.md`.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Implemented Prototype Areas

- Natural language question composer
- Recommended / Frequent examples
- Upload File and Networking entry buttons
- Query plan execution steps
- Metadata panel
- Query result table with row selection
- Summarize Data panel with selected-row validation
